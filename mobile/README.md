# ARC Event Tracker для Android

Устанавливаемое Android-приложение на Capacitor 8, Android 7.0+ (API 24), target SDK 36. Интерфейс и каталог квестов общие с Windows, мобильные стили и системные функции находятся в `mobile/`.

В Android-версии доступны события Embark, регионы, поиск, избранное, завершённые события, 123 квеста с локальным прогрессом, справка и системные напоминания. Статистики игрока, входа Steam и ключей API здесь нет.

В версии 0.5.1 добавлено дерево квестов: отметка задания завершает его и всех обязательных предшественников. Есть масштабирование, перемещение схемы, переход к целям и отмена последней отметки. Последующие задания и соседние ответвления не отмечаются.

[Скачать подписанный APK 0.5.1](https://github.com/maleoipTu/arc-raiders-event-tracker/releases/download/v0.5.1/ARC-Event-Tracker-Android-0.5.1.apk)

## Сборка

Нужны Node 22+, pnpm, JDK 21 и Android SDK (platforms;android-36, build-tools;36.0.0, platform-tools). Укажите `ANDROID_HOME`, либо установите SDK в `.android-sdk/` в корне проекта.

```powershell
pnpm install --frozen-lockfile
pnpm android:test
pnpm android:signing  # один раз: создаёт личный ключ подписи
pnpm android:apk
```

Готовый подписанный APK: `dist/ARC-Event-Tracker-Android-0.5.1.apk`. Если ключ подписи не настроен, собирается APK с отладочной подписью и суффиксом `-debug`. Не распространяйте отладочную сборку как релиз.

Ключ и пароль лежат в исключённой из Git папке `.android-keys/`. Сделайте её резервную копию в безопасное место: без прежнего ключа Android не установит будущий APK поверх текущего. Никогда не публикуйте эту папку. Для CI можно задать переменные `ARC_ANDROID_KEYSTORE`, `ARC_ANDROID_STORE_PASSWORD`, `ARC_ANDROID_KEY_ALIAS`, `ARC_ANDROID_KEY_PASSWORD`.

При выпуске следующей версии увеличьте `version` в `package.json` и `versionCode` в `android/app/build.gradle`. APK с той же подписью обновляет приложение с сохранением данных. Переход с debug-подписи на release-подпись требует удаления debug-версии и удаляет её данные.

## Установка на телефон

Перенесите APK на телефон, откройте его в файловом менеджере, при необходимости разрешите установку из этого источника и подтвердите установку. Для ADB: `adb install -r dist/ARC-Event-Tracker-Android-0.5.1.apk`.

Прогресс квестов и избранное сохраняются в хранилище приложения. При удалении приложения или очистке его данных они пропадают. Автоматического переноса данных с Windows нет.

## Расписание и напоминания

Официальное расписание загружается нативным HTTP-клиентом при запуске и каждые 15 минут, пока приложение открыто. Последняя копия и каталог квестов доступны офлайн. После возврата в приложение данные обновляются.

Уведомления изначально выключены. Включите их в справке и разрешите в Android. Планируется ближайший день из последнего загруженного расписания; открывайте трекер ежедневно. События с одинаковым временем группируются. Используются неточные системные будильники без специального разрешения exact alarms: энергосбережение и ограничения производителя могут задерживать доставку. После принудительной остановки уведомления возобновляются только после запуска приложения.

Обновления проверяются среди публичных GitHub Releases с APK. Windows EXE не предлагаются. APK скачивается в браузере; Android запрашивает подтверждение установки. Фоновой загрузки расписания или автоматической установки APK без участия пользователя нет.

## Проверки

`pnpm android:test` проверяет парсер официального расписания, региональные времена и группировку уведомлений. Скрипт `scripts/check-mobile-ui.mjs` проверяет интерфейс на ширинах 360, 412 и 800 пикселей через Playwright и Chrome (задайте `PLAYWRIGHT_MODULE`, если пакет установлен вне проекта). Нативная сборка запускает Android Lint.

Для проверки на устройстве: загрузка расписания с Wi-Fi/мобильной сети; выбор региона; запуск без сети; прогресс квеста после перезапуска; отказ/выдача разрешения уведомлений; доставка напоминания с погашенным экраном; кнопка «Назад» и поворот экрана. Проверки браузера не заменяют проверку системных функций на Android.
