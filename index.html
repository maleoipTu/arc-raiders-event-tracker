БЫСТРЫЙ СТАРТ

Подключение без лишнего риска

Трекер берёт расписание событий у Embark, данные Steam — через Steam Web API, а статистику рейдов — из ARC Tracker. Пароли не сохраняются.

01

Steam

На вкладке «Игрок» нажмите «Войти через Steam». Вход идёт на официальной странице Steam OpenID.

Даёт имя, аватар и Steam ID.
02

Steam Web API key

Получите ключ на steamcommunity.com, вставьте его в карточку Steam и нажмите «Сохранить и проверить».

Нужен для часов в игре и достижений.
03

ARC Tracker keys

Зарегистрируйте приложение для arc_k1_…, затем создайте личный arc_u1_… с правами Profile и Rounds.

Оба ключа показываются полностью только один раз.
04

ARC Tracker Link

Установите Link, привяжите игровой Steam-аккаунт на arctracker.io и запустите «Sync now». Без Link история рейдов будет пустой.

Даёт рейды, эвакуации, убийства, урон и счёт.

ДИАГНОСТИКА

Если что-то не работает

Статистика показывает нули

Откройте на ARC Tracker раздел Raids. Если там «No raids yet», запустите ARC Tracker Link, обновите привязку Steam и выполните Sync now. Затем нажмите «Обновить данные» в трекере.

Ключи приняты, но ARC Tracker не даёт данные

Проверьте, что User key имеет оба разрешения: Profile и Rounds. Если полное значение ключа утеряно, отзовите его и создайте новый.

Не видно часов или достижений Steam

Добавьте Steam Web API key и убедитесь, что профиль и игровые данные Steam не скрыты настройками приватности.

Истекло подключение к игре

Запустите ARC Tracker Link из меню «Пуск». Если связь не обновилась, на arctracker.io откройте Settings → ARC Raiders account и снова нажмите «Link with Steam».

◆
Где хранятся ключи

Steam API key, ARC App key и ARC User key шифруются Windows DPAPI и остаются на этом компьютере. Не публикуйте их в чатах и на скриншотах.
