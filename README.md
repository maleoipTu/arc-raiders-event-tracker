# ARC Event Tracker

Неофициальное настольное приложение для Windows, которое показывает события и модификаторы карт ARC Raiders в реальном времени.

![Иконка приложения](assets/app-icon.png)

## Возможности

- актуальное расписание событий из официального источника Embark;
- русские названия и описания событий;
- поиск, фильтры, избранное и история завершённых событий;
- системный трей, автозапуск и уведомления Windows;
- вход через Steam OpenID, часы в игре и достижения;
- статистика рейдов из ARC Tracker: эвакуации, убийства, урон и карты;
- встроенная справка, диагностика подключений и центр обновлений;
- локальное шифрование API-ключей через Windows DPAPI.

## Установка

1. Откройте раздел **Releases** справа на странице репозитория.
2. Скачайте `ARC-Event-Tracker-Setup-0.4.0.exe` из последнего релиза.
3. Запустите установщик и выберите установку для текущего пользователя.

Windows может показать предупреждение SmartScreen, поскольку установщик пока не подписан коммерческим сертификатом.

## Подключение статистики

Подробная пошаговая инструкция находится во вкладке **Справка** внутри приложения.

- Steam использует официальный OpenID; приложение не получает пароль.
- Steam Web API key нужен для часов и достижений.
- ARC Tracker App key и User key нужны для истории рейдов.
- ARC Tracker Link должен быть запущен, чтобы синхронизировать игровые данные.

## Разработка

Требуются Node.js и pnpm.

```powershell
pnpm install
pnpm start
```

Сборка установщика:

```powershell
pnpm installer
```

## Конфиденциальность

Steam API key, ARC App key и ARC User key не входят в исходный код. В установленном приложении они шифруются Windows DPAPI и хранятся только в профиле текущего пользователя.

## Статус проекта

Это неофициальный проект сообщества, не связанный с Embark Studios, Steam или ARC Tracker. Названия и товарные знаки принадлежат их владельцам.
