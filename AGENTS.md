# Правила работы над ARC Event Tracker

## Работа без дополнительных агентов

По последнему прямому пожеланию владельца выполняйте задачи самостоятельно.
Не запускайте дополнительных агентов, субагентов и агентов-критиков и не
делегируйте работу другим чатам. Прежнее требование подключать агентов отменено.
Возвращайтесь к делегированию только по новому явному запросу пользователя.

## Интерфейс и данные

Сохраняйте русский язык интерфейса и документации, оформление приложения,
прогресс пользователя и отсутствие статистики игрока в Android-версии.
Не выдавайте неподтвержденные игровые сведения за достоверные.
